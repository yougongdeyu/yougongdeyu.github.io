分布式锁：锁的存在 ≠ 线程是否还在执行
如果业务能严格界定最坏执行时间，那么不需要自动续期，执行完释放锁是最安全、最可控的方式；

Auth：
   saml：“我是谁”
   oauth：我可以做什么
   oauth 和jwt是啥关系
      oauth：是规则，流程
      jwt： token格式

   saml 概念：
      IdP：生成 SAML Assertion（带签名）也就是登录提供方。
      SP： 服务提供方
      SAML Assertion： 令牌 / 凭证
      元数据： metadata IdP / SP 配置文件，包括证书、公钥、端点 URL
   

   IdM 根据 Assertion 生成 OAuth Access Token（通常是 JWT）
   
   OAuth 其实是个协议规范，有好多实现者
      比如定义了 client server，client要注册才能拿token


流程如下：

用户点击 SMAX Portal 登录 → 被重定向到 IdM /authorize
IdM 检查 Session：
如果 Session 已存在 → 用户已认证
如果没有 → 显示登录页
用户登录成功 → Session 建立并且OAuth Server 根据 Client（通过 client_id / redirect_uri）生成 授权码 (Authorization Code)

浏览器重定向回 Client 的 redirect_uri，附带授权码
Client 用授权码去换 Access Token / JWT
Client 使用 Access Token 调 SMAX API
