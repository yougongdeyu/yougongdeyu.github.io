spring bean scope有哪些：
    singleton（default）：单例，无状态
    prototype：每次new 一个对象
    request：用户登录上下文
    session：购物车对象 
    原理：
        Spring 的 request/session scope 只是基于 request.setAttribute 和 session.setAttribute 对生命周期进行了封装。相当于缓存的操作。有消费，无创建+放入

线程安全的容器对象有哪些：
    map：
        hashtable
        concurrenthashmap
        vector
        Collections.synchronizedMap(Map)
    List：
        Vector 线程安全版本的Arraylist
        CopyOnWriteArrayList add的时候，ReentrantLock，复制+ 改+写入volotile 引用。
        Collections.synchronizedList(List)
    Set：
        CopyOnWriteArraySet 基于 CopyOnWriteArrayList 实现，迭代安全
        ConcurrentSkipListSet 并发有序集合，支持排序操作（底层是 skip list）
        Collections.synchronizedSet(Set)
    队列（Queue / Deque）：
        | `ConcurrentLinkedQueue` | 非阻塞队列，适合高并发场景      |CAS + 无锁算法
        | `ConcurrentLinkedDeque` | 双端队列               |
        | `LinkedBlockingQueue`   | 阻塞队列，生产者消费者场景      |
        | `ArrayBlockingQueue`    | 固定容量阻塞队列           |    ReentrantLock + Condition ？？？？？？？？？？ todo
        | `PriorityBlockingQueue` | 并发优先队列             |
        | `SynchronousQueue`      | 直接交接队列，适合线程间直接传递数据 |
        阻塞队列用于线程池、生产者消费者
        非阻塞队列（ConcurrentLinkedQueue）适合高吞吐、低延迟场景
